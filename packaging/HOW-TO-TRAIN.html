Training an agent

The game plays on its own. Teaching it to is a second program — the Missile Defense Trainer — which needs Python. The game does not ship one, because a bundled interpreter with the trainer's Qt bindings is about 200 MB on a download that is otherwise a game.

Once the trainer is installed, you never need this page again: choose TRAIN AI in the game and it starts.

Windows

  1. Install Python 3.12 or newer from python.org/downloads. Tick Add python.exe to PATH during setup.
  2. Start the game and choose TRAIN AI again.

The game installs the trainer for you from the copy that came with it, in a terminal window you can watch. Nothing else is needed.

3.12 and not 3.11: the trainer ships as a wheel built against CPython's stable ABI, which starts at 3.12. pip will refuse it on 3.11.

macOS

  1. Install Python 3.12 or newer — from python.org/downloads, or with Homebrew: 
    brew install python
    The python3 that comes with macOS is 3.9 and too old.
  2. Start the game and choose TRAIN AI again.

Linux

The trainer is a package, and your distribution's Python is managed by your distribution — so it is installed the same way the game was: 

sudo apt install missile-defense-trainer

Then choose TRAIN AI in the game.

Not pip: Debian and Ubuntu mark the system interpreter externally managed (PEP 668), so pip install there is refused by design — correctly. The package brings everything, including the Qt bindings.

From a source checkout

python3 -m tools.bootstrap
poe ui

The game finds a checkout on its own, so TRAIN AI works there without installing anything.

PyTorch

You do not need it to install the trainer, to watch a run, to compare models or to replay episodes. You need it to start a training run — and the trainer will offer to set up a runtime for you, matched to the hardware it finds, from its Set up training… button. That is a several-gigabyte download, which is exactly why it is a button and not a dependency.
